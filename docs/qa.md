**Q1.1**: Какой уровень безопасности BLE использовать?
- **Варианты**: No security, Just Works, Passkey Entry, Out of Band
- **Рекомендация**: Just Works для MVP, Passkey Entry для production
- **Статус**: Требует решения

**Q1.2**: Нужна ли аутентификация устройств?
- **Варианты**: Без аутентификации, PIN-код, MAC-адрес фильтрация
- **Рекомендация**: MAC-адрес фильтрация для простоты
