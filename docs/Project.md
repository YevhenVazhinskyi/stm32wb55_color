# Project: BLE LED Control Device

## Project Overview

### Цель проекта
Создание системы управления 4 светодиодами через Bluetooth Low Energy (BLE) с использованием STM32WB55 в качестве периферийного устройства и Flutter приложения в качестве центрального устройства.

### Основные функции
- Управление 4 независимыми светодиодами
- BLE связь между STM32WB55 и Flutter приложением
- Реальное время управления состоянием LED
- Безопасная передача команд
- Логирование операций

### Компоненты системы

#### 1. STM32WB55 (Периферийное устройство)

- **Платформа**: Flutter (iOS/Android)
- **BLE**: flutter_blue_plus или flutter_ble
- **UI**: Material Design 3
- **Состояние**: Provider/Riverpod

## BLE Протокол

### Сервис LED Control
**UUID**: `12345678-1234-1234-1234-123456789ABC`

#### Характеристики:
1. **LED State** (UUID: `87654321-4321-4321-4321-CBA987654321`)
   - Тип: Write/Notify
   - Размер: 1 байт
   - Описание: Состояние всех 4 LED (битовая маска)

2. **LED Individual** (UUID: `11111111-2222-3333-4444-555555555555`)
   - Тип: Write
   - Размер: 2 байта
   - Описание: Управление отдельным LED (ID + состояние)

3. **System Status** (UUID: `AAAAAAAA-BBBB-CCCC-DDDD-EEEEEEEEEEEE`)
   - Тип: Read/Notify
   - Размер: 4 байта
   - Описание: Статус системы, ошибки, температура

### Формат команд

#### LED State (1 байт)
```
Bit 7-4: Reserved
Bit 3:   LED4 (1=ON, 0=OFF)
Bit 2:   LED3 (1=ON, 0=OFF)
Bit 1:   LED2 (1=ON, 0=OFF)
Bit 0:   LED1 (1=ON, 0=OFF)
```

#### LED Individual (2 байта)
```
Byte 0: LED ID (1-4)
Byte 1: State (0=OFF, 1=ON, 2=TOGGLE, 3=BLINK)
```

## Требования к производительности

### Время отклика
- BLE команда → LED изменение: < 100ms
- Сканирование BLE: < 5 секунд
- Переподключение: < 3 секунды

### Потребление энергии
- Режим ожидания: < 1mA
- Активный режим: < 10mA
- BLE передача: < 20mA

### Надежность
- Время наработки на отказ: > 1000 часов
- Восстановление после сбоя: < 30 секунд
- Логирование ошибок: 100%
