# Development Diary: BLE LED Control Device

## 2024-12-19

### Наблюдения
- Проект STM32WB55 успешно создан с использованием CubeMX
- Базовая структура FreeRTOS настроена и работает
- GPIO конфигурация для 4 LED выполнена
- Makefile настроен для сборки проекта
- Обнаружена проблема с отсутствующими SPI HAL драйверами в Makefile

### Решения
1. **Архитектура проекта**: Принято решение использовать слоистую архитектуру:
   - App/ - прикладной слой
   - Services/ - сервисы (BLE, LED control, error handling)
   - Drivers/ - драйверы (CubeMX + пользовательские)
   - Core/ - системные файлы

2. **BLE протокол**: Определен протокол с тремя характеристиками:
   - LED State (1 байт) - управление всеми LED
   - LED Individual (2 байта) - управление отдельным LED
   - System Status (4 байта) - статус системы

3. **Именование файлов**: Принято соглашение snake_case с префиксом модуля (ble__service.c)

4. **Makefile**: Исправлена проблема с отсутствующими SPI драйверами путем их удаления из списка источников

### Проблемы
1. **Отсутствующие SPI HAL драйверы**
   - **Проблема**: Makefile ссылается на несуществующие файлы stm32wbxx_hal_spi.c и stm32wbxx_hal_spi_ex.c
   - **Решение**: Удалены из C_SOURCES в Makefile
   - **Статус**: Решено

2. **Синтаксическая ошибка в Makefile**
   - **Проблема**: "missing separator" из-за пустой строки в C_SOURCES
   - **Решение**: Удалена пустая строка между записями
   - **Статус**: Решено

3. **Документация проекта**
   - **Проблема**: Отсутствует структурированная документация
   - **Решение**: Создана папка docs/ с Project.md, Tasktracker.md, Diary.md
   - **Статус**: Решено

### Технические решения
1. **FreeRTOS**: Выбран для управления задачами и синхронизации
2. **BLE стек**: Используется встроенный BLE контроллер STM32WB55
3. **GPIO**: Настроены 4 выхода для управления LED
4. **Компилятор**: ARM GCC 14.2 для кросс-компиляции

### Следующие шаги
1. Создать базовый LED драйвер
2. Изучить BLE стек STM32WB55
3. Начать реализацию BLE сервиса
